# Apache 2800 calibration

This directory contains low-material physical fit tests and their validation
records. Calibration identifiers such as T01 and T02 are test identifiers, not
production release revisions.

- `case-fit/final-fit/` — approved four-quadrant case-fit evidence.
- `case-fit/length-fit/` — length and depth gauges.
- `rear-controls/T01/` — first rear-control coupon series.
- `rear-controls/T02/` — second rear-control coupon series.
- `m4-keystone/RP09/` — three-size standard-keystone snap-fit coupon for the
  RP09 M4 Ethernet face.

Passing calibration work may inform a later RP release, but it does not create
the next RP number by itself.
