# Apache 2800 analysis

This directory contains design studies and supporting calculations. These are
not immutable printable releases.

- `airflow/` — enclosure airflow and thermal-envelope study.
- `equipment-tray/` — equipment-tray layout study and fit coupon.
- `rear-power/` — rear power-interface study.
- `recessed-fuse/` — recessed fuse-block support study.
- `tray-routing/RP03/` — historical RP03 tray-routing study.
- `apache_2800_fit_analysis.py` and `FIT_ANALYSIS.md` — comparison with the
  Apache 2800 reference CAD model.

Approved printable files are published under `../releases/`.
