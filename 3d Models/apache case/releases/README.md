# Apache 2800 model releases

This directory contains immutable, curated print releases. Read `current.json`
to identify the version that should be printed and installed.

Each release contains production meshes, installation guides, previews,
validation evidence, release notes, and a SHA-256 manifest. Editable historical
source is recovered from the `source_tag` recorded in that manifest.

Do not edit a released RP folder. Begin the next sequential version under
`../versions/RPNN` for every later geometry change.
