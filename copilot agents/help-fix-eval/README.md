# Help Fix eval sets

One CSV per mode, 20 conversations each (the Copilot Studio import limit).
Questions are the exact prompts the kiosk sends. The response column is a reference list of required steps; Studio does not compare it automatically. Order may vary and wording may differ (e.g. a named Remove step instead of Remove all other cables).

## Mode 1: Smart Thermostat (`thermostat`)

Required cables: LAN 1 to LAN 2

1. Fault start: every switch wrong, no cables -> 7 step(s)
2. Switches correct, no cables -> 1 step(s)
3. Required cables present, every switch wrong -> 6 step(s)
4. Switches correct, one extra cable on top of the required ones -> 1 step(s)
5. Switches correct, only a wrong cable plugged in -> 2 step(s)
6. Required cable present in reversed port order, Switch 1 wrong -> 1 step(s)
7. Only Switch 1 wrong, cables correct -> 1 step(s)
8. Only Switch 2 wrong, cables correct -> 1 step(s)
9. Only Switch 3 wrong, cables correct -> 1 step(s)
10. Only Switch 4 wrong, cables correct -> 1 step(s)
11. Only Keyed switch 1 wrong, cables correct -> 1 step(s)
12. Only Keyed switch 2 wrong, cables correct -> 1 step(s)
13. Switch 1 and Switch 2 wrong, no cables -> 3 step(s)
14. Both keyed switches wrong, no cables -> 3 step(s)
15. Switches 1, 3 and Keyed switch 1 wrong, wrong cable plugged in -> 5 step(s)
16. Only Switch 4 wrong, no cables -> 2 step(s)

18. Every switch wrong, wrong cable plugged in -> 8 step(s)
19. Only Switch 1 correct, required cables present -> 5 step(s)
